# Grand Theft Auto: Vice City - Web 3D 🌴🚗

基于原生 Web 标准与 Three.js 纯前端 3D 引擎构建的《侠盗猎车手：罪恶都市》（GTA: Vice City）高清网页版。单个 `index.html` 即可在现代浏览器中流畅运行，零依赖、零后端。

## 🎮 游戏介绍

本作在现代浏览器中还原了经典的 80 年代迈阿密开放世界体验：

- **角色与探索**：扮演主角 Tommy Vercetti，在海滨大道、棕榈树与霓虹 Art Deco 建筑群之间自由探索。
- **三栖载具系统**：
  - **PCJ-600 仿赛摩托车**：支持双轮压弯侧倾、翘头加速 (Wheelie) 与刹车翘尾 (Stoppie)，具备极高的推重比与灵活性。
  - **Kaufman Cab 复古出租车**：发光 TAXI 顶灯与经典棋盘格拉花，支持鸣笛（ 键）与出租车拉客支线任务（ 键）。
  - **Infernus 超跑**：高极速、强抓地力与真实漂移烧胎音效。
  - **Squalo 动力快艇**：停靠于东海岸码头，具备真实正弦波浪浮力与船用节速表。
  - **Rhino 犀牛重型坦克**：配备 360° 旋转独立炮塔与 120mm 重型主炮，可直接碾碎压爆民用与警用车辆。
- **武器与战斗**：
  - 支持多武器自由切换：拳头搏击、UZI-9MM 冲锋枪、SPAS-12 散弹枪、PSG-1 高精狙击步枪（右键开镜）、M2 火焰喷射器、RPG-7 高爆火箭筒。
  - 动态城市生态：沿街漫步的市民 NPC、双向巡航的民用交通流。
  - 击倒目标掉落旋转美金钞票，实时吸附结算。
- **警力与通缉度**：
  - 犯罪即时提升 6 星通缉等级。
  - 地面黑白警车高速包夹截停。
  - 2 星以上出动 **VCPD Maverick 武装直升机** 盘旋伴飞并投射高动态强光探照灯。
  - 阵亡触发经典电影级暗角红幕 **WASTED** 特效，并在医院就近满血重生。
- **原生声学引擎与车载电台**：
  - 纯 Web Audio API 程序化合成所有音效，无需下载外部音频资源。
  - 包含引擎调频轰鸣、枪炮爆鸣、雨声雷暴及 3 大车载合成波电台（Flash FM / Wave 103 / V-Rock）。
- **经典秘籍系统**：
  - 键盘直接敲击输入秘籍指令，即刻触发绿色弹跳横幅提示与特殊能力（如 `ASPIRINE` 满血、`PRECIOUSPROTECTION` 满护甲、`PANZER` 空降坦克、`NUTTERTOOLS` 满弹药、`LEAVEMEALONE` 清除星级）。

## 🕹️ 操作指南

| 动作 | 步行模式 | 载具模式 (靠近按 `F` / `Enter` 驾驶) |
| :--- | :--- | :--- |
| **移动 / 驾驶** | `W` `A` `S` `D` | `W` (油门) / `S` (刹车/倒车) / `A` `D` (转向) |
| **视角旋转** | 鼠标滑动 (点击画面锁定指针) | 第三人称电影视角平滑跟随 |
| **疾跑** | 左 `Shift` | 按住 `W` 持续提速 |
| **跳跃** | `Space` 空格键 | - |
| **上下车/船/坦克** | `F` 或 `Enter` | `F` 或 `Enter` |
| **攻击 / 开火** | 鼠标左键 (开枪 / 挥拳) | 鼠标左键 (坦克发射 120mm 重炮) |
| **切换武器** | `Q` / `E` | - |
| **车载电台** | - | `R` 切换电台 |
| **天气切换** | `T` (晴天 / 迈阿密暴风雨) | `T` |

## 🚀 运行方式

无需任何构建或后端配置，直接使用现代浏览器打开 `index.html`，或通过本地静态服务器启动：
```bash
python3 -m http.server 8080
```
浏览器访问 `http://localhost:8080` 即可开始游玩。

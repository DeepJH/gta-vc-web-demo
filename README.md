# Grand Theft Auto: Vice City - Web 3D 纯网页重构版 🌴🚗

基于原生 Web 标准与 Three.js 纯前端 3D 引擎从零重构的《侠盗猎车手：罪恶都市》（GTA: Vice City）高清网页版。

**零依赖、零后端安装要求**：只需要一个静态 HTML 文件，即可在任何现代浏览器（Chrome、Edge、Firefox、Safari、手机平板）中全速运行。

---

## 🌟 核心特性 (v0.2)

- 🎮 **纯原生 HTML5 / WebGL 3D 架构**：
  - 基于 Three.js 独立运行，支持 PCF 柔和阴影与高清视距渲染。
  - 经典迈阿密 80 年代黄昏粉紫天际线与海滨氛围。
- 🏃 **经典主角 Tommy Vercetti 角色系统**：
  - 经典夏威夷短袖衬衫与牛仔裤建模。
  - 支持第 3 人称越肩视角平滑跟踪、鼠标指针锁定全向视角、跳跃与疾跑。
- 🏎️ **经典超跑 Infernus 载具系统**：
  - 经典超跑高尾翼与白/霓虹配色。
  - 靠近按 `F` 或 `Enter` 平滑上下车。
  - 真实车辆加速、刹车减速与转向运动学。
- 📟 **经典 Vice City 霓虹 HUD**：
  - 80s 风格霓虹血量、护甲、金钱与当前装备武器显示。
  - 实时雷达 MiniMap 小地图，动态标注道路与车辆坐标。

---

## 🚀 运行方式

### 极速体验
直接双击打开 `index.html`，或使用任何本地静态服务器：
```bash
python3 -m http.server 8000
```
访问 `http://localhost:8000` 即可开始游玩。

## 🕹️ 键位操作

| 操作 | 步行模式 | 载具模式 (靠近按 F 上车) |
| :--- | :--- | :--- |
| **移动 / 驾驶** | `W` `A` `S` `D` | `W` (油门) / `S` (刹车倒车) / `A` `D` (转向) |
| **视角** | 鼠标滑动 (Pointer Lock) | 第三人称电影视角自动跟随 |
| **加速 / 疾跑** | 左 `Shift` | 按住 `W` 持续提速 |
| **上下车** | `F` 或 `Enter` | `F` 或 `Enter` |
| **跳跃** | 空格键 `Space` | - |
| **开火** | 鼠标左键 | - |

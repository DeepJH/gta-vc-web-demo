# Grand Theft Auto: Vice City - Web 3D Edition 🌴🚗

基于原生 Web 标准与 Three.js 纯前端 3D 引擎构建的《侠盗猎车手：罪恶都市》（GTA: Vice City）单文件高清网页版。

**零依赖、零后端**：无需安装任何复杂环境，单个 `index.html` 即可在现代浏览器（Chrome、Edge、Firefox、Safari、移动端）中流畅运行。

---

## 🎮 快速开始

### 本地运行
直接双击打开 `index.html`，或通过本地静态服务器启动：
```bash
python3 -m http.server 8080
```
浏览器访问 `http://localhost:8080` 即可开始游玩。

## 🕹️ 操作指南

### 1. 基础控制

| 动作 | 步行模式 | 载具模式 (靠近按 `F` / `Enter` 驾驶) |
| :--- | :--- | :--- |
| **移动 / 驾驶** | `W` `A` `S` `D` | `W` (油门) / `S` (倒车/刹车) / `A` `D` (转向) |
| **视角旋转** | 鼠标滑动 (点击画面锁定指针) | 第三人称电影视角跟随 |
| **疾跑** | 左 `Shift` | 按住 `W` 持续提速 |
| **跳跃** | `Space` 空格键 | - |
| **上下车/船/坦克** | `F` 或 `Enter` | `F` 或 `Enter` |
| **攻击 / 开火** | 鼠标左键 | 鼠标左键 (坦克发射 120mm 重炮) |
| **切换武器** | `Q` / `E` (拳头 / 微冲 / 散弹枪 / 火箭筒) | - |
| **车载电台** | - | `R` 切换电台 (Flash FM / Wave 103 / V-Rock) |
| **天气切换** | `T` 键 (晴朗天际线 / 迈阿密暴风雨) | `T` 键 |

### 2. 经典秘籍 (键盘直接键入)

游戏中直接在键盘敲击对应秘籍字母即可生效：

| 秘籍指令 | 功能说明 |
| :--- | :--- |
| `ASPIRINE` | 恢复 100% 满生命值 |
| `PRECIOUSPROTECTION` | 恢复 100% 满防弹护甲 |
| `PANZER` | 空降传奇陆战霸主 **Rhino 犀牛重型坦克** |
| `NUTTERTOOLS` / `THUGSTOOLS` | 补满所有武器与火箭筒弹药 |
| `LEAVEMEALONE` | 一键清除所有警方通缉星级 |

## 🌟 核心游戏系统

### 1. 开放世界与海陆空载具
- **三栖载具**：
  - **Infernus 超跑**：高极速、带尾翼与真实漂移抓地声。
  - **Squalo 动力快艇**：停靠于东海岸码头，具备真实正弦波浪浮力水面物理与船用节速表（Knots）。
  - **Rhino 犀牛坦克**：360° 旋转独立炮塔、可摧毁压扁民用车与警车、配备毁灭性高爆主炮。
- **动态立体城市**：
  - 双向巡航民用交通流（Traffic Flow Engine）。
  - 漫步巡逻的迈阿密市民 NPC，受击倒地后掉落可拾取美金钞票。
  - 80s 霓虹 Art Deco 建筑群与黄金海岸线。

### 2. 武装对抗与警力通缉系统
- **多武器轮盘**：拳头近战挥击、UZI-9MM 冲锋枪、SPAS-12 散弹枪、RPG-7 重型高爆火箭发射器。
- **6 星警力系统**：
  - 犯罪即时提升通缉星级。
  - 地面 AI 巡警车极速包夹截停。
  - 2 星以上出动 **VCPD Maverick 武装直升机**，双旋翼盘旋伴飞并投射高动态强光探照灯。
- **WASTED 死亡特效**：
  - 阵亡触发经典电影级暗角红幕与慢动作，随后于 Ocean Beach 医院就近重生。

### 3. 原生 Web Audio 声学引擎
- 纯程序化合成，无需下载外部音频资产：
  - 发动机动态调频轰鸣、轮胎漂移尖叫、多种枪炮射击声与超低频爆炸冲击波。
  - 3 大车载合成波电台（Flash FM, Wave 103, V-Rock）琶音贝斯律动。
  - 降雨白噪与雷暴轰鸣环境声回路。

## 📜 版本更新历程

- **v0.10 - 终极巅峰版**：引入经典秘籍输入系统（`ASPIRINE`, `PANZER` 等）、Rhino 犀牛主战坦克与碾压物理、WASTED 电影级死亡红幕与医院重生。
- **v0.9 - 爆炸破坏与海空作战**：加入 RPG-7 火箭发射器、海岸栈桥码头与 Squalo 快艇浮力物理、警方 Maverick 武装直升机与夜间追踪探照灯。
- **v0.8 - 交通流与多武器库**：加入双向民用交通巡航、Q/E 武器轮盘（拳头/微冲/散弹枪）、漂移烧胎音效与 CRT 胶片暗角。
- **v0.7 - 动态天气与昼夜**：按 T 键切换迈阿密暴雨与雷电闪光、环境雨声循环与动态光照。
- **v0.6 - 车载电台与黑帮任务**：加入 Flash FM / Wave 103 / V-Rock 80s 电台与合成贝斯律动、街头黑帮悬赏任务与 $10,000 奖励。
- **v0.5 - 市民 NPC 与经济系统**：加入漫步路人、受击击倒反应、击杀掉落旋转美金与吸附拾取结算。
- **v0.4 - 巡警与 AI 追击**：黑白警车实体、红蓝警灯闪烁、合成警笛警报与包夹撞击 AI。
- **v0.3 - 声效与六星通缉**：Web Audio 引擎轰鸣与枪声、UZI 弹道系统、六星通缉度与 MPH 仪表盘。
- **v0.2 - 纯 WebGL 3D 架构重构**：从旧版彻底重写为纯 HTML5/Three.js 单文件架构，实现 Tommy Vercetti 人物控制器、Infernus 超跑与霓虹 HUD。
- **v0.1 - 初始原型探索**。
